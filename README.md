# 图维绩效管理平台

面向 50 人左右规模企业的全栈绩效管理系统。前端为单页应用（无外部依赖），后端 Flask + SQLite，数据存放在本地 `perf.db`，支持员工／评分主管／绩效HR／最终审核人／系统管理员五类角色，权限在服务端强制校验。

## 快速开始

```bash
# 1. 安装依赖（Python 3.10+）
pip install -r requirements.txt

# 2. 初始化数据库并写入演示数据（含周文文 2026-09 真实实例）
python seed.py

# 3. 启动（默认端口 8600，可用 PORT 环境变量修改）
python app.py
```

浏览器访问 `http://127.0.0.1:8600`。

## 员工端入口与自评表单

- 每位用户登录后进入「我的工作台」：待填写自评数量统计、待办卡片（含「立即填写自评」按钮）、评分进行中与已发布结果列表；侧边栏「我的任务」带待办红点。
- 自评表单字段与 Excel《业务目标设定及评估表》逐列对齐：
  - 表头信息：员工姓名、职位名称、所属部门、直属主管、评估周期、任务编号
  - 指标表列：序号、目标/关键业务领域名称及描述、衡量标准&100%目标值、衡量标准&120%目标值、数据来源（部门：文档名称）、权重%（单项10%-60%）、评估结果（实际完成情况）、员工自评（0-120分）
  - **指标定义字段员工可编辑**：名称、100%/120% 目标值、数据来源、权重均由员工在自评时填写（初始值取自任务快照），服务端校验单项权重 10%-60% 且合计 100%
  - 员工版生效范围：员工提交后，主管评分、HR 核对与校准、结果发布均按员工版指标计算；任务中的原始指标快照保留在「任务详情-指标快照」供对照
  - 合计行：总权重与加权自评总分实时计算（权重合计必须 100%）
  - 加减分提示：评估加减分（-10~+10）由总监级及以上人员在评分环节填写，员工端不开放
  - 员工确认签字：提交前须勾选「本人确认以上自评内容真实有效」并输入签名（电子签名），服务端强制校验
  - 动态指标行：点击「＋ 增加指标」添加自定义指标行，勾选行后点「删除选中」移除（至少保留一项）；序号自动重排；删除/新增行的名称、目标值、来源、权重均由员工填写，权重合计须为 100%（单项 10%-60%）

## 业务规则（与Excel模板一致）

- 每位员工 4-7 项指标，单项权重 10%-60%，合计 100%
- 评分区间 0-120 分：员工自评、主管评分、同级评分（选填）
- 业务目标得分 ＝ Σ（主管评分 × 权重）
- 总分 ＝ 业务目标得分 ＋ 加分（0-10）＋ 减分（-10-0）
- 当期奖金系数 ＝ MIN(总分, 120) / 100
- 绩效等级按总分区间自动套用（默认：≥110 S、≥100 A、≥90 B、≥80 C、其他 D，可在「等级规则」修改）

## 流程与隔离设计

1. **员工考核配置**：HR 维护每人考核频率（月度／季度／两者）、月度／季度评分主管、最终审核人、指标与权重。
2. **考核任务**：HR 按周期批量生成，指标快照固化进任务，配置变更不影响历史任务；同一员工同一周期唯一。
3. **员工自评**：员工填写完成情况、自评分与附件，提交后流转到评分主管，可被退回修改。
4. **内部评分审批**：主管逐项评分（可校准加减分）→ HR 核对 → 最终审核人审核。内部审核意见与对员工公开的反馈分两个字段存放。
5. **已发布绩效结果**：审核通过后由 HR 发布，员工只能查看本人的结果，无编辑权。

权限要点（均在服务端校验，前端隐藏只是体验）：

- 员工只能读写自己的任务与结果；内部评分表对员工完全不可见（接口层 403/404）
- 主管只能看到「评分主管＝本人」的任务
- HR 与管理员可见全量数据；管理员权限仅限必要人员
- 附件经登录态接口下载，不做公开静态目录
- 登录失败限流（同 IP 10 次/10 分钟）、密码 scrypt 加盐哈希、会话 12 小时过期
- 关键操作（评分、发布、重置密码等）全部记入审计日志

## 已知边界（第二阶段可选）

- 定时自动生成任务与到期提醒（当前由 HR 手动批量生成＋站内通知）
- 员工线上申诉流程（当前签字确认随自评提交完成）
- 与钉钉／企业微信的组织架构和消息打通
- 多人绩效校准会（强制分布）视图

## 部署

本地或内网服务器：`pip install -r requirements.txt && python app.py`（默认端口 8600）。
生产建议置于反向代理（Nginx 等）之后并启用 HTTPS；50 人规模 Flask 内置服务器即可承载，如并发增长可改用 waitress/gunicorn 部署。
